# Prüfung auf zwei echten Smartphones

Stand: vorbereitet, noch nicht durchgeführt. Das Team hat den Gerätetest auf später verschoben.

1. Rechner und beide Handys im selben WLAN. Auf dem Rechner `npm run dev -- --host
   <WLAN-IPv4>` starten. Die ausgegebene App-Adresse `http://<WLAN-IPv4>:8091` auf
   beiden Geräten öffnen oder Expo Go nach den ausgegebenen Hinweisen verwenden.
2. Auf jedem Gerät ein anderes Testkonto erstellen. Modell, Betriebssystem,
   Browser/Expo-Go-Version, Datum und getesteten Git-Stand notieren.
3. Handy 1: einen eigenen Plan mit zwei Übungen erstellen. Sätze, Textwiederholungen,
   Reihenfolge, Gewicht 0, Pause 0 und Notiz setzen. Im Kalender einplanen und erneut öffnen.
4. Profil speichern, Makroziel berechnen und Tageswerte erfassen. Einen anderen
   Kalendertag als Ruhetag speichern. Vorherige Inhalte nur bewusst ersetzen.
5. Browser/App vollständig schliessen, neu öffnen und gegebenenfalls erneut anmelden.
   Trainings-, Plan-, Profil- und Makrowerte mit den eingegebenen Werten vergleichen.
6. Handy 2: Konto B darf private Daten von Konto A nicht sehen. Anschliessend auf
   Handy 2 mit Konto A anmelden und dieselben gespeicherten Daten vergleichen.
7. API auf dem Rechner stoppen, einen Entwurf speichern wollen: verständliche
   Fehlermeldung, Entwurf bleibt erhalten. API neu starten und bewusst erneut speichern.
8. Datumswechsel, lange Namen, Schriftvergrösserung, Tastatur und Scrollen prüfen.

Pro Schritt das tatsächlich beobachtete Ergebnis und bestanden/fehlgeschlagen notieren.
Bei einem Fehler Schritt, Gerät und Meldung festhalten. Keine fremden echten Personen-
oder Gesundheitsdaten als Testdaten verwenden. Die Browserautomation ersetzt diesen Nachweis nicht.
